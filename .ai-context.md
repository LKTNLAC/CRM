# AI CONTEXT

Project: Language School CRM
Stack: FastAPI + PostgreSQL + Redis + React + TypeScript
Repo: https://github.com/LKTNLAC/CRM

## Quy tắc cho AI

1. Đọc HANDOFF.md trước.
2. Không đổi architecture.
3. Không hard-code secret.
4. Luôn viết migration khi đổi schema.
5. Luôn chạy test trước khi báo hoàn thành.
6. Báo cáo theo format: STATUS / WHAT WAS DONE / FILES / IMPACT / TEST.

## Entry points

- Backend: `backend/app/main.py`
- Router: `backend/app/api/v1/router.py`
- Frontend: `frontend/src/main.tsx`
- Routes: `frontend/src/routes/index.tsx`

## Module pattern
modules/<name>/
├── domain/ # Pure logic, no framework
├── application/ # Use cases, service
├── infrastructure/ # ORM, repository
├── schemas.py # Pydantic
├── router.py # FastAPI
└── permissions.py # RBAC constants
